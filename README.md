# Ernests skolas demo lapa

Maza, jautra un vienkarsa viena lapa GitHub Pages videi.
Lapa paredzeta Ernesta prezentacijai klase, lai vins var paradit, ko sodien redzeja un iemacijies.

## Konteksts

Ernests ir 12 gadus vecs un sodien seko lidzi senior full-stack izstradataja darbam.
Vins macaas Bergu Muzikas un makslas pamatskola, klase 6.b.
Lapas merkis ir paradit klasesbiedriem, ka tehnoloģijas var but interesantas, bet aiz tam stav realas prasmes un domasana.

## Tehniskais virziens

- Statiska lapa GitHub Pages
- HTML
- Tailwind CSS
- Vienkars JavaScript
- Bez backend pirmaja versija

## Galvena ideja

Lapai jabut personigai, rotaļigai un viegli demonstrējamai klase.
Tai nav jabut parak lielai vai sarezgitai.
Pirmajai versijai svarigakais ir, lai ta strada droshi un Ernests var to pats izstastit.

## Galvenais vestijums

Ernests sodien iemacijās, ka labs darbs IT nav tikai koda rakstisana.
Svarigas ir arī soft skills, spēja komunicet, uzdot labus jautajumus un skaidri izskaidrot idejas.
Svarigs punkts: AI ir noderigs riks, bet bez zināšanām tas nav ipasi verts.
Ja nesaproti pamatus, tu nevari novērtēt, vai AI atbilde ir laba, slikta vai pilnigi nepareiza.

## V1 saturs

- Ievads: kas ir Ernests
- Kur Ernests macaas
- Ko vins sodien iemacijās
- Ko dara izstradatajs ikdiena
- Ko nozime soft skills
- Ko AI var un ko AI nevar
- Skolas lokacijas bloks ar saiti uz karti
- Dažas jautras interaktivas pogas ar jokiem, faktiem vai parsteigumiem

## Interaktivitates idejas

- Poga "Pastasti joku"
- Poga "Interesants fakts"
- Poga "Ko sodien iemacijos?"
- Poga "Mini, ko dara full-stack izstradatajs"
- Poga "Kur ir mana skola?"
- Mazs tests ar 3 jautajumiem
- Jautrs "dienas sasniegums" vai "developer badge"

## Satura piezimes

Pirmajai versijai labak izmantot lokalu datu masivu JavaScript, nevis areju joku API.
Tas bus stabilak demonstracijai klase un vieglak kontrolet valodu un saturu.
Lokacijas dalai pirmaja versija pietiek ar skolas nosaukumu, adresi un pogu, kas atver karti jaunaa cilne.
Iebuvetu karti var pievienot velak, ja tas tiesam uzlabo demonstraciju.
